# Dental Clinic Management System

## 1. Project Name

**Dental Clinic Management System**

## 2. Project Purpose

The purpose of this project is to develop a computerized system for managing the daily operations of a dental clinic. The system helps manage patients, dentists, appointments, services, billing, and reports while reducing manual record keeping.

## 3. Technologies Used

* Java
* MySQL
* JDBC (Java Database Connectivity)
* IntelliJ IDEA
* Git
* GitHub

## 4. System Requirements

* Java JDK 17 or later
* MySQL Server
* IntelliJ IDEA or another Java IDE
* Windows operating system
* Minimum 4 GB RAM
* Git for version control

## 5. Database Setup

1. Install and start MySQL Server.
2. Create a database for the application.
3. Import the provided SQL database script.
4. Update the database connection details in the Java configuration.
5. Ensure that the MySQL server is running before starting the application.

The application uses JDBC to connect to the MySQL database.

## 6. Instructions for Using the Application

1. Open the project in IntelliJ IDEA.
2. Ensure that Java JDK and MySQL are correctly configured.
3. Start the MySQL server.
4. Configure the database connection.
5. Run the main Java application.
6. Log in to the system.
7. Use the navigation menu to access the required modules.
8. Add, view, update, or delete records as required.

## 7. Main System Features

* User Login
* Dashboard
* Patient Management
* Dentist Management
* Appointment Management
* Service Management
* Billing Management
* Reports
* CRUD Operations

## 8. Testing Information

The system was tested to verify the main functionalities and database operations. CRUD operations, user input validation, appointment management, patient management, billing, and database connectivity were tested to ensure that the system functions correctly.
