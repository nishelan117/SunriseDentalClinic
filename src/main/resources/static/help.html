Help & User Guide

Learn how to use the Sunrise Dental Clinic Management System

🦷 Welcome to Sunrise Dental Clinic

This guide provides information about the main features of the Sunrise Dental Clinic Management System. Use the sections below to manage patients, dentists, appointments and billing efficiently.

👤

Patient Management

  • Add new patient details.
  • Search patients by name, email or phone.
  • Edit existing patient information.
  • Delete patient records when required.
🧑‍⚕️

Dentist Management

  • Add dentist details and specialization.
  • Search dentists by name or specialization.
  • Edit dentist information.
  • Delete dentist records.
📅

Appointment Management

  • Create new appointments.
  • Appointment numbers are generated automatically.
  • Select a dentist from the available dentist list.
  • Select treatment type, date, time and status.
  • Edit or delete appointments.
🧾

Billing Management

  • Select an appointment for billing.
  • Enter treatment and bill amount.
  • Select payment status.
  • Save and manage bills.
  • Print bills when required.
📊

Dashboard

The dashboard displays the total number of patients, dentists, appointments and bills. It also displays pending appointments and total revenue.
